## 移动VPS应该看什么？不要只看 CPU 和内存

很多 VPS 对比文章会把重点放在：

* 几核 CPU
* 多少 GB 内存
* SSD 容量
* 月流量

这些当然重要，但对于移动网络用户来说，还有几个容易被忽略的因素。

### 节点位置影响访问距离

服务器离用户越近，通常网络延迟越低。

例如：

* 中国大陆用户访问香港、日本节点，物理距离较近；
* 美国西海岸节点通常适合连接北美用户，也常被用于面向亚洲的跨境业务；
* 洛杉矶节点因为靠近太平洋网络枢纽，常见于连接亚洲和北美的应用场景。

DMIT 官方目前提供洛杉矶、香港、东京等区域选择，并针对不同区域提供不同网络线路。

### 网络线路比端口速度更值得关注

VPS 页面上的 1Gbps、10Gbps 代表端口能力，但实际体验还取决于：

* 上游网络质量；
* 路由路径；
* 高峰期拥堵情况；
* 用户所在地区。

例如同样是 10Gbps 端口，不同线路访问同一个地区可能会有明显差异。

### 用途决定配置，不需要盲目购买高配

常见用途大致可以这样参考：

| 用途 | 建议关注 |
| --- | --- |
| 个人博客、小型网站 | 1-2 vCore、2GB 内存通常足够 |
| WordPress、多站点 | 2-4 vCore、4GB 内存更灵活 |
| API、程序测试 | CPU 和内存优先 |
| 数据处理、较高并发应用 | 更高配置套餐 |
| 跨地区访问业务 | 节点和线路优先 |
